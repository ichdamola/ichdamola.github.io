    Reworked the billing data model and moved slow third-party calls off the request path.

    How it worked
    Problem

    Uploads per 10K-recipient media send

    Before10,000

    360Dialog · WhatsApp messaging · 2026

    Media-ID cache for the WhatsApp/Meta API

    A Redis cache of media IDs, so one upload serves a whole send instead of one upload per recipient.

    30+ enterprise brands and 1.5M+ end customers on the platform

    How it worked
    Problem
    On a WhatsApp messaging platform serving 30+ enterprise brands and 1.5M+ end customers, sending one piece of media to 10,000 recipients meant 10,000 uploads to the Meta media API.
    What I built
    A Redis-backed cache of media IDs, so a file is uploaded once and its ID is reused across the whole send.
    How
    Cached media IDs in Redis, used ETag revalidation to detect when the source file changes, and added distributed locks so concurrent workers do not upload the same file twice.
